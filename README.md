### 3. Fibonacci Sequence
```python
# Generating a Fibonacci sequence
def fibonacci(n):
    a, b = 0, b = 1
    for _ in range(n):
        print(a, end=" ")
        a, b = b, a + b

# Print first 10 numbers
fibonacci(10)
```
